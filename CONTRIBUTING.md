# Contribuições

Faça fork, trabalhe em sua cópia e abra uma proposta com problema, comportamento resultante e validação. Execute `npm test`, `npm run build` e `npm run audit`. Nunca envie .local, .env.local, contas, tokens, gravações pessoais, manuscritos ou conteúdo de clientes. Preserve autoria e licenças. As 41 gravações do pacote não precisam de uma chamada de geração para teste ou reparo.
